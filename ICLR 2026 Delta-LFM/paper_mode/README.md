# paper_mode

논문(`2512.09185v4.pdf`) 설정으로 Delta-LFM을 다시 실행하기 위한 폴더입니다.
레포 기준 벤치마크는 이미 완료됐고(`../RECIPE.md`, 결과는 `../ae_runs/fm_eval/`), 그 실행을 다시
돌릴 수 있게 보존하기 위해 논문 버전은 여기에만 둡니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `PAPER_SETTINGS.md` | 논문 명시 설정 vs 레포 실행 설정 대조표, 결정 필요 항목 |
| `2512.09185v4.pdf` | 논문 원문 |
| `src/` | 레포 파일의 사본(수정본)과 논문 버전 신규 모듈 |
| `scripts/` | 논문 버전 학습/평가 스크립트 |
| `notebooks/` | 논문 버전 분석 노트북 |
| `outputs/` | 논문 버전 체크포인트, latent, 평가 결과 (레포 버전 `../../outputs`와 분리) |
| `docs/` | 실행 기록, 중간 검증 메모 |

## 격리 규칙

1. 레포 코드와 레포 버전 산출물은 **읽기만** 합니다.
2. 레포 파일을 고쳐야 하면 이 폴더로 **사본을 만든 뒤 사본만** 수정하고, 파일 머리에 원본 경로와
   변경 요지를 주석으로 적습니다.
3. 출력 루트는 항상 `paper_mode/outputs`입니다.

## 현재 상태

`PAPER_SETTINGS.md`의 결정 항목 D1~D8 승인 대기 중입니다. 코드 작성은 승인 후 시작합니다.
